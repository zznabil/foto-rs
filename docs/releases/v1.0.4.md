# Foto 1.0.4

First public GitHub distribution of the minimal native Windows photo viewer.

- Fix draft-release lookup so independent download verification can finish before publication. Preserve the unpublished 1.0.3 candidate and immutable tag as historical evidence.
- Update the fixture-generation tool to Pillow 13.0.0 and add recurring Python advisory checks. Pillow is not part of the viewer executable.
- Keep all eight native toolbar controls visible on narrow/high-DPI windows through adaptive row wrapping.
- Include long-path, filename-casing, held-fullscreen-key and Enter-button fixes, plus decoded-image reuse from 1.0.2.
- GPL-3.0-or-later source, complete vendored Cargo dependencies and third-party notices.
- Pinned CI, Rust compatibility checks, Defender scans, schema-validated SPDX inventory, checksums, an isolated offline source rebuild and GitHub build provenance.
- Publish only after a separate Windows runner downloads, verifies, scans and smoke-tests the release artifacts.

Download `Foto-1.0.4-windows-x64.zip`, extract it, and run `foto.exe`. No installation or separate VC++ runtime is required. Corresponding source is `Foto-1.0.4-source.zip`.

The executable is not Authenticode-signed. Windows 10, human UAT and real multi-monitor transitions remain independently unverified. GIF/TIFF display their first frame; optional formats depend on installed Windows codecs. No new startup or universal performance claim is made. See [the Defender investigation](../DEFENDER.md) for the affected 1.0.2 hash and evidence limits; Microsoft has not confirmed a false-positive determination.
