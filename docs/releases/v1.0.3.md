# Foto 1.0.3

First public GitHub distribution of the minimal native Windows photo viewer.

- Portable x64 Windows ZIP with native folder browsing, zoom, pan, rotation and full screen. Photos remain read only.
- Includes the long-path, filename-casing, fullscreen-repeat and keyboard-button fixes from 1.0.1, plus decoded-image reuse from 1.0.2.
- GPL-3.0-or-later source and notices; complete vendored Cargo dependency source supplied alongside the binary.
- Windows product/file version metadata, pinned CI, minimum-Rust compatibility check, dependency advisory/license checks, SPDX inventory, checksums and GitHub-hosted build provenance.
- Tagged tests and an isolated offline source rebuild precede a draft. An independent download/provenance/native-window check must pass before publication.

Download `Foto-1.0.3-windows-x64.zip`, extract it, and run `foto.exe`. No installation or separate VC++ runtime is required. Corresponding source is `Foto-1.0.3-source.zip`. See the supplied README and repository verification instructions.

The executable is not Authenticode-signed. Windows 11 local testing and Windows Server CI do not establish separate Windows 10, human UAT or real multi-monitor coverage. GIF/TIFF display their first frame; optional image formats depend on installed Windows codecs. Images beyond the decoded-buffer limits use an identified reduced preview. No startup speedup or universal performance claim is made. No breaking application behavior change is intended in this packaging release.
