# Foto 1.0.5

Maintenance release for the development and release-validation toolchain.

- Update rpds-py from 2026.6.3 to 2026.9.1. It supports SPDX schema validation through jsonschema and is not included in foto.exe.
- Verify every pinned artifact hash against PyPI and re-run the native viewer, dependency, Defender, packaging, offline source rebuild and provenance gates.
- Viewer features and runtime dependencies are unchanged. No new performance claim is made.

Download `Foto-1.0.5-windows-x64.zip`, extract it, and run `foto.exe`. No installation or separate VC++ runtime is required. Corresponding source is `Foto-1.0.5-source.zip`; GPL-3.0-or-later licensing and third-party notices are included.

The executable is not Authenticode-signed. Windows 10, human UAT and real multi-monitor transitions remain independently unverified. GIF/TIFF display their first frame; optional formats depend on installed Windows codecs. Microsoft has not confirmed a false-positive determination for the older 1.0.2 executable. See [the Defender investigation](../DEFENDER.md).
